# 磐石交易AI：单策略下拉交互设计

日期：2026-07-28
状态：已确认

## 目标

策略选择器无论当前有一个还是多个策略，都必须可以点击展开。单策略场景
不能退化为静态文本，也不能依赖不同操作系统表现不一致的原生下拉菜单。

## 交互

- 默认显示当前策略名称、版本、状态和下拉箭头。
- 点击按钮展开策略列表；只有一个策略时仍展示一行选项。
- 当前策略显示选中标记。
- 点击当前策略只关闭列表，不触发重新分析。
- 点击不同策略时调用现有策略切换接口并生成新分析版本。
- 点击组件外部、按 `Escape` 或完成选择后关闭列表。
- 支持 `Enter`、空格、上下方向键和焦点管理。
- 接口失败时恢复原选择并在组件内展示错误。

## 架构

策略数据继续完全来自 `GET /v1/strategies` 和策略注册表。前端只实现通用
展示与选择，不写死策略名称，也不创建虚假策略。组件使用 `button`、
`role="listbox"` 和 `role="option"` 实现可访问的自定义弹层。

## 验收

- 真实单策略数据下，点击“分析策略”可以看到一项策略列表。
- 单项显示“结构确认策略”“v1.0.0”和“稳定版”。
- 选择当前项不会发起策略切换请求。
- 多策略测试数据下，选择其他策略仍生成新分析版本。
- 首页与案例页使用相同组件。
