# 磐石交易AI 产品说明书

> 本说明书面向最终用户，帮助你快速上手磐石交易AI。

---

## 1. 磐石交易AI 是什么？

磐石交易AI 是一个**策略商店 + 策略化预测分析助手**。

在这里，你可以：

- **浏览策略商店**：查看不同策略最近三个月的表现。
- **购买/订阅策略**：获得策略的完整使用权限。
- **使用策略分析**：用自然语言让策略帮你分析标的。

你只需要用自然语言告诉系统：

- 你想分析哪个标的（比如螺纹钢、黄金、沪深300）
- 你想用哪个策略（比如趋势突破、结构确认、事件驱动）
- 你当前的持仓情况（可选）

系统会自动获取行情数据、事件因子等信息，运行策略模型，然后告诉你：

- 未来一段时间的方向判断
- 关键支撑和阻力位
- 触发条件
- 失效条件
- 风险提示

**磐石交易AI 不是交易软件**，不会替你下单。它只提供分析和决策参考。

## 2. 核心特点

### 2.1 看最近三个月表现选策略

每个策略都展示最近三个月的实际表现：涨跌多少、产生多少次信号、对了多少次、最大一次亏了多少。你可以像看商品评价一样，先看表现再决定是否购买。

### 2.2 像聊天一样使用

不需要学习复杂界面，直接输入文字即可。

示例：

```text
用趋势突破策略分析一下螺纹钢。
```

### 2.3 策略决定需要哪些信息

不同策略需要的信息不同。系统只问你当前策略真正需要的信息，不会一次性抛出大量表单。

### 2.4 数据由系统自动提供

行情数据、技术指标、事件因子等由系统自动获取和计算。你不需要上传 Excel、连接行情软件或手动填写 K 线数据。

### 2.5 结果可解释

每个结论都告诉你：用了什么策略、依据是什么、数据来源、置信度如何、什么情况下结论会变化。

### 2.6 支持多种输入方式

- 文字输入
- 上传图片/截图
- 上传文件（PDF 等）

### 2.7 信息不足时会告诉你

如果当前信息不足以运行策略，系统不会硬给结论，而是明确告诉你还缺什么、为什么需要、怎么补充。

## 5. 最近三个月表现怎么看？

每个策略都会展示最近三个月的实际表现，帮助你判断这个策略是否值得购买。

### 5.1 核心指标

| 指标 | 含义 | 怎么看 |
|---|---|---|
| 整体涨跌 | 最近三个月累计涨跌幅度 | 正数代表涨，负数代表跌 |
| 信号次数 | 最近三个月产生了多少次信号 | 次数越多，参考意义越大 |
| 盈利次数 | 信号中赚钱的次数 | 越多说明效果越好 |
| 亏损次数 | 信号中亏钱的次数 | 结合胜率一起看 |
| 胜率 | 盈利次数 / 总信号次数 | 越高说明稳定性越好 |
| 最大回撤 | 期间最大一次亏损 | 越小说明风险越小 |

### 5.2 收益曲线

收益曲线展示策略资金在最近三个月的变化。你可以直观地看到：

- 整体是向上还是向下
- 中间有没有大幅回落
- 是否长期横盘

### 5.3 信号记录

信号记录展示策略最近三个月每次发出的信号：

```text
日期         标的      方向      结果
2025-08-11   RB2510   做多      盈利 +1.2%
2025-08-08   RB2510   观望      无
2025-08-05   RB2510   做空      亏损 -0.8%
```

通过这些记录，你可以了解策略的实际风格：

- 是频繁交易还是偶尔出手？
- 盈利和亏损分别是什么情况？
- 是否适合你的交易习惯？

### 5.4 注意事项

- 最近三个月表现基于历史行情计算，不代表未来收益。
- 市场环境变化可能导致策略失效。
- 表现好的策略不一定适合你，建议结合自身风险偏好选择。

## 6. 如何购买策略

### 6.1 购买方式

策略支持以下购买方式：

| 方式 | 说明 | 适合人群 |
|---|---|---|
| 免费 | 无需付费，直接使用 | 所有用户 |
| 单次购买 | 一次性付费，永久使用当前版本 | 想长期使用某策略 |
| 月度订阅 | 按月付费 | 想灵活尝试 |
| 年度订阅 | 按年付费，通常有折扣 | 长期跟踪某策略 |

### 6.2 购买流程

1. 在策略详情页点击「购买」或「订阅」。
2. 选择购买方案。
3. 查看权益说明和风险提示。
4. 确认支付。
5. 支付成功后，策略自动进入「我的策略」。

### 6.3 我的策略

在「我的策略」中可以看到：

- 所有已拥有的策略。
- 每个策略的授权状态：永久、订阅中、已过期。
- 订阅到期时间。
- 续费按钮。

### 6.4 订阅到期

订阅到期后：

- 不能新建分析。
- 可以查看历史分析记录。
- 可以点击「续费」恢复使用。

## 10. 系统会问你要什么信息？

系统需要的信息由你选择的策略决定。常见需要确认的信息包括：

| 信息 | 场景 | 是否必须 |
|---|---|---|
| 分析标的 | 每次分析都需要 | 是 |
| 分析周期 | 日线/小时线等 | 否，有默认值 |
| 当前持仓方向 | 策略需要判断持仓是否匹配信号 | 取决于策略 |
| 持仓数量 | 风险评估 | 取决于策略 |
| 持仓成本 | 止损距离计算 | 取决于策略 |
| 止损设置 | 风险控制 | 取决于策略 |
| 风险承受能力 | 仓位建议 | 取决于策略 |

**原则**：系统只问当前策略真正需要的信息。行情数据、技术指标等由系统自动获取，不会让你填写。

## 11. 如何补充信息

当系统需要你补充信息时，会以对话消息的形式问你一个具体问题。

示例：

> 为了完成风险判断，我需要知道你当前的持仓情况。你可以回复：
> - "我目前空仓"
> - "我有多仓2手，成本16020"
> - "我不想提供持仓，只做方向分析"

你可以用自然语言回答，不需要填写表单。系统会解析你的回答，并展示它的理解：

> 我理解为：你当前空仓。请确认是否正确？

确认后，信息进入证据链，系统继续运行策略。

## 12. 如何理解分析结果

### 12.1 结论卡片

每次分析结果以卡片形式展示，默认包含：

- **策略和版本**：例如"结构确认策略 v1.0"
- **标的和周期**：例如"CF2609 日线"
- **一句话结论**：例如"未来5个交易日方向中性偏空"
- **置信度**：0% - 100%
- **关键价位**：支撑位、阻力位等
- **触发条件**：什么情况下信号会强化
- **失效条件**：什么情况下结论不再成立
- **风险提示**：与你的持仓方向冲突时的提示

### 12.2 置信度说明

- **80% 以上**：信号较强
- **60%-80%**：信号一般，需结合其他信息
- **60% 以下**：信号较弱，建议观望

### 12.3 可视化图表

点击「查看K线」可以看到：

- K 线图
- 指标线（如 MACD、BOLL）
- 信号标记
- 关键价位标注

### 12.4 策略链路

点击「查看详情」可以看到策略运行的每一步：

```text
1. 数据有效性    ✓ 已确认
2. 市场状态      ✓ 下降趋势
3. 策略形态      ✓ 趋势反抽做空
4. 价格位置      ✓ 中轨下方
5. 量仓行为      ✓ 持仓增加
6. 动能状态      △ 候选
7. 价格确认      ✗ 未触发
8. 风险与动作    ✓ 等待
```

## 13. 如何追问

分析完成后，你可以继续提问。追问分为几类：

### 13.1 解释型追问

只解释当前结论，不改变分析结果。

```text
为什么偏多？
第3步是什么意思？
依据是什么？
```

### 13.2 情景推演

基于假设条件推演，结果不覆盖真实结论。

```text
如果跌破3550会怎样？
如果我有多仓，应该怎么做？
```

### 13.3 事实修正

你提供新的事实，系统生成新的分析版本。

```text
我刚才说错了，我其实是空仓。
```

### 13.4 策略切换

```text
用趋势突破策略再看一下。
```

如果策略未购买，系统会提示你去策略商店查看。

### 13.5 刷新分析

```text
重新分析一下，用最新行情。
```

## 15. 常见问题

### 15.1 磐石交易AI 会帮我下单吗？

不会。磐石交易AI 只提供分析和决策参考，不连接实盘交易系统。

### 15.2 我需要选择底层大模型吗？

不需要。大模型是系统后台能力，你只需要和系统自然对话。

### 15.3 分析结果保证准确吗？

不能保证。任何分析都有不确定性，磐石交易AI 会给出置信度，但市场走势可能超出预期。请结合自身判断使用。

### 15.4 为什么系统有时不给我结论？

当策略运行所需的信息不足时，系统会拒绝运行并请你补充。这是为了避免在低信息状态下给出不可靠结论。

### 15.5 我可以上传截图吗？

可以。截图可以帮助系统确认你关注的标的、周期或形态。但行情数据主要由系统自动获取。

### 15.6 不同策略结论不一样怎么办？

不同策略从不同角度分析市场，结论可能不同。你可以根据自身交易风格和风险偏好选择合适的策略。

### 15.7 我的持仓信息安全吗？

安全。你的持仓等敏感信息仅用于当前分析，不会用于模型训练，也不会泄露给第三方。

### 15.8 购买后可以退款吗？

具体退款规则以平台公示为准。部分策略可能支持"7天无理由退款"或"未使用可退款"。

### 15.9 最近三个月表现好就一定能赚钱吗？

不一定。最近三个月表现是历史统计，未来市场环境可能变化。请把它作为参考，而不是收益保证。

### 15.10 为什么有的策略最近三个月表现是跌的？

策略风格不同，有的策略在某些市场环境下会表现不好。你可以结合胜率、最大回撤等指标综合判断。

## 16. 使用建议

### 16.1 选策略看综合表现

不要只看涨跌幅度。建议同时关注：

- 信号次数
- 盈利次数
- 胜率
- 最大回撤
- 收益曲线是否平稳

### 16.2 结合自身风险偏好

一个涨跌大但胜率高的策略，可能适合激进型用户；一个波动小但胜率一般的策略，可能适合保守型用户。

### 16.3 描述清晰

尽量明确说出标的、周期和策略名称。

```text
推荐：用趋势突破策略分析螺纹钢日线，目前空仓。
一般：螺纹钢怎么看？
```

### 16.4 提供必要信息

如果策略需要你的持仓信息，请尽量提供，这样系统可以给出更贴合你实际情况的建议。

### 16.5 关注置信度和失效条件

高置信度不意味着稳赚，低置信度也不意味着没有机会。更重要的是理解触发条件和失效条件。

### 16.6 多策略对照

对同一个标的可以使用不同策略进行分析，比较不同视角的结论。
